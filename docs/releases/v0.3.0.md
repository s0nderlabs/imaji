This is a launch. v0.3.0 is the first release imaji's own Mind can announce in every format a developer actually posts.

What changed:

- A launch video. When a release is a launch, the Mind directs it: it writes a storyboard of beats (a line, a screenshot from the repository, a live capture of the product's homepage, three lines of what changed, a sign-off) and imaji renders it as a 30 to 45 second film.
- A vertical cut of the release film at 1080 by 1920 for Shorts, Reels and TikTok, rendered alongside the landscape one.
- Standing preferences in an optional `imaji.json` at the repository root: which outputs you want by default, the look, and when a launch video is worth making. The Mind honours it as a default and still decides per release; chat still wins for taste and one-off overrides.
- A setup path for coding agents: `imaji.s0nderlabs.xyz/agents.md` walks an agent through handing the developer's own Mind the job, minting a token, wiring the workflow and running onboarding, asking the developer only for the API key and the Mind ID. The job itself is served at `/job.md`.
- New identity: the hand-lettered imaji wordmark, Tigerlily as the one accent, warm neutrals, and the card and film re-set in Adventor and Open Sauce One. The version tag is a pixel face.
